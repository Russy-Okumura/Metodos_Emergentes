##  Descripción
Este repositorio tiene el objetivo de documentar un control de actividades realizadas por el equipo #2 en la materia de Metodos Emergentes de 19:00 - 20:00 

## Actividad 1: analisis de un proyecto fallido

- Cada equipo analiza el proyecto Quibi
- Identifican problemas de planificacion, comunicacion o integracion de codigo o proyecto
- Proponen la estrategia Kanban para reestructuracion del proyecto que incluye:
    - backlog inicial
    - roles 
    - iteraciones
    - objetivos por sprint

### Evidencias

- Repositorio que trabajaran en proyecto 
- Documento inicial con backlog y roles en formato Markdownen el repositorio
- Creacion de un tablero Kanban en github con tareas asignadas a cada miembro (los roles seran los mismos para el proyecto de la materias)
