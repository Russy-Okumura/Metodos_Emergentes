## Actividad 1: analisis de un proyecto fallido

- Cada equipo analiza el proyecto Quibi
- Identifican problemas de planificacion, comunicacion o integracion de codigo o proyecto
- Proponen la estrategia Kanban para reestructuracion del proyecto que incluye:

    - roles 
    - iteraciones
    - objetivos por sprint
